# Chatter (fullstack project) Spring boot 3, Angular 17, Bootstrap, PostgreSQL, Docker (2024) (Backend + Frontend)

Angular online chat project, in collaboration with a Spring backend. This project allows users to log in, create channels, send messages, and participate in discussions.

## Chatter Backend

### Key Features

- **Channel Creation:** Users can create new channels to organize discussions.
- **Channel Deletion:** Users can delete existing channels.
- **Channel List:** Displays the list of available channels.
- **Message List:** Displays all messages within a specific channel.
- **Channel Renaming:** Users can rename existing channels.
- **Adding Messages:** Users can send messages in channels.

### Technologies Used

- **Java 17:** Adopted as the primary version of the programming language, Java 17 offers modern features and performance improvements, contributing to the application's robustness and security.
- **Maven:** Used as the project management system, Maven simplifies configuration and dependency management, ensuring a consistent project structure.
- **Spring Boot:** Used as the primary backend framework, offering simplified development management.
- **Spring Data JPA:** Used for data persistence management, facilitating database operations.
- **Spring Service, Repository:** Used to implement business service and data access layers, these Spring components facilitate the separation of concerns and promote code maintainability.
- **PostgreSQL:** Relational database integrated for development, ensuring stability and performance.

## Chatter Frontend

### Key Features

- **Authentication:** Users can log in to the application.
- **Channel Creation:** Users can create new channels to organize discussions.
- **Channel List:** Displays the list of available channels.
- **Adding Messages:** Users can send messages within channels.

### Technologies Used

- **Angular 17:** Used as the primary frontend framework, providing an interactive user experience.
- **Bootstrap and Custom:** Used for a responsive and attractive design.
- **RxJS:** Used for reactive programming within Angular, facilitating data stream management.
